Overview

A full-stack web application that replaces a small café's paper menu with a digital one. Staff can add, edit, and remove menu items in real time, with changes persisted to a cloud database and instantly reflected on the frontend — no page reloads.

What this project taught me

  • Building a complete CRUD system end-to-end: Vue 3 frontend, Express REST API, MongoDB Atlas database.
  • Structuring a Mongoose schema and connecting a real cloud database to a live single-page app.
  • Debugging real integration issues (frontend/backend connection, CORS, initial DB creation) rather than working from a spec alone.
  • Responsive UI design with Flexbox for a clean, mobile-friendly menu display.

Stack & architecture

  • Frontend: Vue 3 SPA + Axios — add/edit form, card-based menu display, edit/delete actions.
  • Backend: Node.js + Express — GET /menu, POST /menu, PUT /menu/:id, DELETE /menu/:id, with CORS enabled and basic field validation.
  • Database: MongoDB Atlas + Mongoose — each item stores name, price, and category, persisted in a menus collection.

Project flow

User fills the form → Vue sends an Axios request → Express receives it and talks to MongoDB Atlas → the item is stored → the response updates the menu list in real time → edits and deletes save back to MongoDB automatically.

Challenges & solutions

  • Frontend ↔ backend connection: solved with Axios HTTP requests to the Node API.
  • Database not appearing: resolved by adding the first document through the Vue form, which auto-created the DB.
  • Responsive styling: handled with CSS Flexbox and media queries.
